## Projects

### Termexa

A desktop application for device communication, debugging, command automation, and automated testing.

Built with Python and PyQt, with support for Serial, TCP, and UDP communication.

**Key features:**
- **Terminal** — Send Text or Hex commands and monitor device responses in real time
- **Command Files** — Load reusable command lists for fast device interaction
- **Communication Recording** — Record terminal logs as text or capture raw received bytes
- **Serial, TCP & UDP** — Communicate with devices over multiple connection types
- **Builder** — Create reusable command sequences and automated test flows
- **Runner** — Execute tests with loops, delays, expected responses, timeouts, and response validation
- **License Management** — Server-backed activation and license management system

🌐 **Website:** https://termexa.pages.dev

> Termexa is actively developed as a private-source project.
